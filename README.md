# MessHallAPI BepInEx
A Custom API to handle a bunch of stuff like 
- Loading Asset Bundles and storing them in a dictionary.
- Loading a modstamp so you dont have to!
- Custom Cosmetic's Registery EX: Nameplates, Visors, Hats, Backpack, and Pets! (Gloves and skins coming soon)
- A Network transform so you can sync Vanilla and Custom GameObjects to every client.
- Custom RPC's
- Custom RPC Protection
- Custom Role Handling
- Custom Power and Targeted Action Handling
- HandShake
- Custom Panels
- Custom Gamemode Handling (Planned)
- Custom Map Registery (Planned)
